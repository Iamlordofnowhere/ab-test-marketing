# 📢 A/B Тест: Анализ маркетинговой кампании

## Описание
Статистический анализ результатов A/B теста маркетинговой кампании.
588,101 пользователей разделены на две группы: реклама (ad) и социальная реклама (psa).

## Цель
Определить влияет ли показ рекламы на вероятность того, что пользователь совершит покупку.

## Инструменты
- Python, pandas, numpy
- scipy (Z-тест, T-тест)
- matplotlib

## Гипотезы
- **H0:** реклама не влияет на вероятность покупки
- **H1:** реклама увеличивает вероятность покупки
- **Уровень значимости:** α = 0.05
- **Тип теста:** односторонний

## Результаты

| Метрика | PSA (контроль) | Реклама (тест) |
|---|---|---|
| Пользователей | 23,524 | 564,577 |
| Покупок | 420 | 14,423 |
| Конверсия | 1.79% | 2.55% |

### Эффект рекламы
- Абсолютный прирост: **+0.769 п.п.**
- Относительный прирост: **+43.1%**
- Доверительный интервал (95%): **[0.565%, 0.974%]**
- P-value: **0.000000** (< 0.05)

## Вывод
**H0 отвергнута** — реклама статистически значимо увеличивает вероятность покупки.
Рекламную кампанию рекомендуется запустить на всю аудиторию.
